# 🎓 ALX Capstone Project  for School Management System (React + Vite)

A modern, responsive web application to manage school operations including student registration, class management, and more — built using **React**, **Vite**, and **TypeScript**.

---

## ✨ Features

- 🔐 User Authentication (Login, Register, Reset Password)
- 🧑‍🎓 Student & Teacher Registration
- 🏫 Class and Institution Management
- 📋 Dynamic Forms with Validation
- 📱 Responsive UI with TailwindCSS
- ⚡️ Fast bundling and development with Vite

---

## ⚙️ Tech Stack

| Technology     | Description                         |
|----------------|-------------------------------------|
| React + Vite   | Frontend Framework & Bundler        |
| TypeScript     | Strongly-typed JavaScript           |
| TailwindCSS    | Utility-first CSS Framework         |
| React Hook Form| Form state management & validation  |
| React Router   | Client-side routing                 |
